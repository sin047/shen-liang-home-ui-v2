# 材质系统

**状态：视觉方向已确认；技术实现 RESEARCH / EXPERIMENT**

## 1. 目标材质

- 水晶：清透、折射、高光和细腻边缘；
- 玻璃：局部半透明、柔和模糊和背景层次；
- 丝绸 / 缎带：柔软曲线、轻微光泽；
- 蕾丝：作为局部边缘或纹理，不铺满正文；
- 银色金属：用于少量边框、挂链和连接细节；
- 纸张与拼贴：用于记录、信笺和卡片内容。

## 2. 强度原则

- 先保证文字、图标和交互状态清楚，再追求材质效果。
- 不要求每个面板都使用玻璃或折射。
- 高复杂度材质优先做独立原型，不直接铺到整站。
- 动效应克制，并提供减少动态效果时的静态回退。
- 装饰图层不得拦截点击或拖动，也不得遮挡可交互控件。

## 4. 实现风险

教程案例提示，CSS backdrop-filter、SVG 位移滤镜和 WebGL 折射在不同浏览器及 WebView 中表现并不一致。构建通过或样式出现在 bundle 中，不代表目标设备上真正呈现了预期材质。

需要分别验证：
- 目标设备是否支持对应能力；
- 背景是否真实穿透，而不是复制一张壁纸造成贴纸感；
- 滚动时坐标与遮罩是否稳定；
- 帧率、GPU 负载和温升是否可接受；
- 不支持时是否回退到普通模糊、渐变或静态材质。

## 5. 结构边界

材质主题不能覆盖布局属性。导航位置、sticky 行为、消息间距、滚动定位、组件尺寸和触控热区必须由布局系统负责。

## 6. 禁用元素

不使用珍珠装饰元素；不使用玫瑰轮盘。生成图中的相关装饰不构成采用依据。
