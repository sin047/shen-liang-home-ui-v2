# 导航方案

**状态：B + E 组合方向已确认；具体交互待细化**

## 1. 方案来源

讨论中的导航概念分为：
- A — The Ribbon：丝带导航；
- B — The Chatelaine：珍宝挂链导航；
- C — The Cabinet：珍宝匣 / 物件式空间导航；
- D — The Rosette：玫瑰轮盘；
- E — Layered Navigation：分层组合导航。

用户选择 B + E 作为方向。D 已明确排除。

## 2. B：珍宝挂链

B 的核心是古典首饰挂链与吊牌的物件美学。它提供明确的空间入口，同时带有收藏物件般的仪式感。

设计注意：
- 吊牌的视觉外形可以不规则，但实际点击区域必须稳定、足够大。
- 当前空间、选中状态和未读状态需要清楚表达。
- 链条、吊坠和装饰不能压缩主要内容区或遮挡底部安全区。
- 具体是固定、悬浮、收起还是展开状态，仍待确认。

## 3. E：分层导航

E 的概念是将不同层级的导航职责分开：
1. 第一层：日常全局空间入口；
2. 第二层：Home / Room 等空间内部的情境导航；
3. 第三层：当前场景的高频快捷操作。

这是一种信息架构方向，不表示三个层级都必须同时常驻显示。实际层级数量、触发方式和响应式形态待设计。

## 4. B + E 的首页组合

当前概念方向：
- 以洛可可珍宝匣式主视觉建立首页识别度；
- 结合 B 的物件美学和 E 的分层结构；
- 支持向下滚动进入日常记录、日期、待办、照片和生活片段；
- 首页不只是一排功能图标，而是一个有内容、有层次的生活入口。

## 5. 空间关系

- 日常 Chat 与 Workroom 分开。
- Reading 是 Together 的一部分。
- Atelier 在概念图中出现，但是否对应 Workroom 尚未确认。
- Room 的功能尚未定义，不能根据概念图标签推断。

## 6. 需要继续讨论

- 全局入口有哪些，最终名称是什么；
- B 的挂链与 E 的分层如何组合；
- 移动端与桌面端的布局关系；
- 空间内部导航何时出现、如何返回；
- 快捷操作的数量、分组与隐藏规则；
- 选中、未读、加载、禁用和异常状态。
