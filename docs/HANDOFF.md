## 2. 产品方向

- 默认主题：雾蓝珍藏室（Mist Blue Treasure Room）。
- 视觉：甜美洛可可 + 水晶洛可可，结合古典拼贴、艺术化排版和拟物素材。
- 导航：B + E，即珍宝挂链与分层导航结合。
- 首页：珍宝匣式主视觉，向下浏览日常记录、日期、待办、照片和生活片段。
- 日常 Chat 与 Workroom 分开。
- Reading 属于 Together。
- 默认主题完整精致，同时支持未来主题扩展与区域混搭。
- 不使用玫瑰轮盘，不使用珍珠装饰。
