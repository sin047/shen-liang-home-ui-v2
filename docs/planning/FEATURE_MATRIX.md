# 功能矩阵

**状态：规划中 · 只记录当前有依据的范围**

| 模块 | 已知目标 | 当前状态 | 备注 |
|---|---|---|---|
| Home | 珍宝匣式主视觉；向下浏览日常记录、日期、待办、照片与生活片段 | CONFIRMED | 内容排序和卡片行为待细化 |
| 日常 Chat | 独立的日常聊天空间 | CONFIRMED | 具体聊天能力不在本轮预设 |
| Workroom | 与日常 Chat 分开的工作空间 | CONFIRMED | 最终名称、子功能待确认 |
| Together | 共同内容空间 | CONFIRMED | Reading 已确认属于其中 |
| Reading | 作为 Together 的一部分 | CONFIRMED | 阅读体验与数据来源待确认 |
| Atelier | 概念图中的工作室式入口 | RESEARCH | 是否等同 Workroom 尚未确认 |
| Room | 概念图中的独立入口 | DEFERRED | 不能根据名称推断功能 |
| 日间主题 | 雾蓝氛围色卡 | CONFIRMED | 原始色卡值见 DESIGN_BASELINE |
| 夜间主题 | 苍闇森林色卡 | CONFIRMED | 原始色卡值见 DESIGN_BASELINE |
| 主题扩展 | 默认主题完整，同时支持后续主题扩展 | CONFIRMED | 具体主题包机制待设计 |
| 区域混搭 | 允许未来按区域组合不同主题风格 | CONFIRMED | 覆盖优先级与控制方式待设计 |
| 水晶 / 玻璃材质 | 作为视觉候选方向 | EXPERIMENT | 需性能与设备验证 |
| 语音 / 通话 | 教程与组件资料中有相关案例 | DEFERRED | 不代表本项目已确认需要 |
| 主动消息 / 记忆系统 | 参考教程涉及 | DEFERRED | 不在当前前端基线中预设 |

## 状态说明

- CONFIRMED：用户明确确认的产品方向。
- RESEARCH：概念出现过，但语义或来源尚未确认。
- EXPERIMENT：需要单独原型验证。
- DEFERRED：暂不纳入当前范围。

新增功能前，先补充目标用户体验、入口、触发方式、状态变化、异常处理和验收标准。
