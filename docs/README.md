# 文档总览

本目录是项目的长期知识库。聊天用于探索和讨论，仓库文档用于保存经确认的事实、研究结论和当前状态。

## 先读什么

1. [HANDOFF](HANDOFF.md)：新窗口或新代理首先阅读，了解当前阶段、进度和下一步。
2. [DECISIONS](DECISIONS.md)：查看哪些内容已确认、哪些已淘汰。
3. [PRODUCT](planning/PRODUCT.md)：了解产品目标与空间关系。
4. [DESIGN_BASELINE](design/DESIGN_BASELINE.md)：了解当前视觉基线。
5. 按任务阅读对应专项文档，不要只凭记忆修改。

## 目录说明

### planning/
产品定位、功能边界、阶段路线和待确认问题。

### design/
视觉基线、导航、主题、材质、视觉参考与素材使用规范。

### research/
用户提供的教程提炼、已知风险，以及第三方组件候选。

### engineering/
尚未锁定的架构边界与未来质量验收要求。

## 文档状态

所有未确认内容必须显式标记为 PROPOSED、RESEARCH、EXPERIMENT 或 DEFERRED。只有用户明确确认的内容才进入 CONFIRMED；验收完成后才可进入 FROZEN。
