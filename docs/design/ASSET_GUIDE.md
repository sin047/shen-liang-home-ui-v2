# 素材使用规范

**状态：工作原则；具体素材来源逐项审核**

## 1. 优先使用可拆分素材

对于复杂拟物界面，优先考虑透明 PNG、SVG 或可编辑的独立图层，而不是把整张页面压成一张不可编辑的大图。

建议流程：
1. 先分析素材尺寸、透明区域和可用内容窗口；
2. 保留原始 PNG / SVG，不直接修改原件；
3. 在独立预览页面中测量素材边框、按钮、阴影和内容区域；
4. 使用 HTML / CSS 在可用区域叠加真实文字与交互内容；
5. 保持原图比例，使用像素级测量，避免拉伸；
6. 将滚动、点击、拖动和响应式缩放实现为真实交互；
7. 分别检查桌面与手机尺寸。

## 2. 参考案例提炼

用户提供的素材讨论截图强调：
- 先分析素材，不急着修改原图；
- 使用独立 preview 页面验证；
- 原 PNG 可作为外框或窗口皮肤；
- 中间内容区域由 HTML / CSS 承载；
- 保持原图比例并使用像素化测量；
- 右侧和底部滚动条可以做成真实可拖动交互；
- 正式项目暂时不动，先独立预览验证。

## 3. 授权与公开范围

当前 GitHub 仓库为 Public：
- 不上传未获授权的付费 PNG / SVG 原件或整套素材包；
- 不因能够下载就推断允许修改、公开或再分发；
- 逐项记录素材来源、作者、许可证、署名要求、允许用途和版本；
- 仅在许可允许时才提交原始文件；
- 无法确认授权时，先记录来源和预览，不提交素材字节。

## 4. AI 生成图的使用边界

AI 生成概念图用于探索构图和氛围，不应直接作为真实页面的唯一实现。图中文字、图标和控件可能存在错误，且生成图中的装饰不自动成为产品决定。

## 5. 素材清单建议字段

未来建立资产目录时，每项至少记录：
- 资产名称与文件路径；
- 来源链接 / 作者；
- 许可证和署名要求；
- 是否允许修改、商用和再分发；
- 使用的页面 / 组件；
- 原始文件与派生文件的关系；
- 最后核验日期。
