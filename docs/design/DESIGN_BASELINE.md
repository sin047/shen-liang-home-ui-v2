# 设计基线

**项目主题：雾蓝珍藏室（Mist Blue Treasure Room）**  
**基线版本：0.1 · 规划参考，不是最终 Design System**

## 1. 视觉定位

以雾蓝与银色为基调，融合甜美洛可可、水晶洛可可、古典拼贴、艺术化排版与拟物素材。整体应有收藏室、珍宝匣和私人空间的仪式感，同时保持轻盈、安静、可长期使用。

## 3. 视觉语言

- **材质**：水晶、玻璃、丝绸、缎带、蕾丝、银色金属细节、纸张与拼贴。
- **形态**：珍宝匣、吊牌、挂链、古典相框、信笺、收藏卡片。
- **排版**：古典展示字体与清晰正文并置；装饰字体仅作少量点缀。
- **构图**：层次丰富但不拥挤，主视觉明确，内容区留白充分。
- **氛围**：柔和、安静、精致、有空间感；避免过度闪烁和高频动态装饰。

## 4. 明确排除

- 不使用玫瑰轮盘式导航。
- 不使用珍珠装饰元素。
- 概念图里出现的玫瑰、珍珠、花朵或其他装饰，不因出现在生成图中就自动成为设计要求。
- 装饰不能遮挡文字、按钮、滚动区域或触控热区。

## 5. 尚未冻结的规格

字体家族、字号阶梯、行高、间距尺度、圆角、边框、阴影、动效时长、组件状态、断点和语义色尚未定稿。不得在施工时把临时视觉判断当作最终 Design System。

## 6. 响应式方向

仓库最初 README 提到 Mobile-first / PWA-first，可作为当前待验证方向。最终设备范围仍需确认。任何页面规格都要同时考虑窄屏、触控、安全区、键盘弹起、滚动和横向溢出。

## 7. 设计原则

1. 先定义信息层级，再叠加装饰。
2. 主视觉与真实内容分层，避免整页图片化。
3. 色彩 Token 与材质效果分离。
4. 材质不能擅自改变布局行为。
5. 日夜主题都必须保持文字可读和交互状态清楚。
6. 生成图只用于探索方向；落地前必须有可测量、可实现的设计规格。
